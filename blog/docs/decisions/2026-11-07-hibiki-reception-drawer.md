# Decision: Hibiki 改為右側抽屜裡的「公會櫃檯」

**Date**: 2026-11-07
**Status**: Accepted

## Context

Hibiki 原本在桌機以全身 Live2D 站在畫面右下，搭配深藍／紫色的「問 Hibiki TALK」入口與視覺小說風格對話框；平板、手機各有不同的入口與面板。使用者認為角色、聊天框與台詞的呈現都與網站的墨綠筆記本風格不一致，但要保留功能，並提出：開一個右側抽屜，角色像遊戲公會櫃檯小姐站在裡面，下方聊天。

## Decision

- 平常只顯示一個網站風格的入口按鈕（手機文章頁維持底部操作列入口）；打開後從右側滑出抽屜，上半部是櫃檯場景（佈告欄牆、角色、櫃檯桌與名牌），下半部是對話。
- Live2D 模型改為第一次打開抽屜才載入；L2Dwidget 產生的 `#live2d-widget` 搬進櫃檯並以 CSS 覆寫定位。關閉時沿用 rAF 包裝暫停繪製。
- 移除全身模式、透明 hitbox、收起／再顯示 Hibiki 與 `hibiki-hidden` 偏好：角色不再常駐頁面，不需要這些機制。
- 抽屜為 modal：遮罩、Tab 循環、Esc 關閉、焦點還原、背景不捲動。配色全部改用網站 tokens，深淺色自動跟隨。
- 聊天邏輯、Worker 介面、文章上下文與待機台詞的頻率上限不變。

## Consequences

- 好處：角色不再遮擋內文與連結，首頁不必先下載模型；視覺與網站一致；桌機、平板、手機共用同一套抽屜，版面規則大幅簡化。
- 壞處：角色只有打開抽屜才看得到，「站在頁面上陪讀」的存在感降低；訪客無法再「收起」入口與待機台詞（台詞每頁最多 4 次）。
- 舊的 Hibiki 版面記錄（2026-09-28 的 full／compact 模式表）已由 SDD 新章節取代；rAF 暫停決策（2026-09-28）仍有效。
