# Decision: 公開的 About 頁只以「Lin」出現，不寫全名與公司

**Date**: 2026-09-28
**Status**: Accepted

## Context
`/portfolio/` 的 Hero 寫了全名「林立人 Jerry Lin」和公司名，但那頁設了 `noindex`，只能從作品集 PDF 的 QR 進入，部落格選單也沒有連結。
`/about/` 則會被搜尋引擎收錄，而且任何讀者都點得到。這次依自傳與作品集 v1.5 更新 About 頁，需要決定公開頁面要露出多少身分資訊；同時，About 頁的內容又要跟申請文件一致，避免審查教授點進來看到矛盾的說法。

## Decision
- About 頁的名字維持「Lin」，跟站台 `author`、首頁 hero 一致；不寫全名、英文名、公司名，產品名也不出現。
- 學校與科系照寫（銘傳大學 人工智慧應用學系）。
- 獎項用模糊寫法：「專題曾獲全國大專院校競賽獎項與校內專題研究獎」，不寫競賽全名、獎項名稱，不放獎狀照片（照片上有全名與隊友姓名）。
- 工作經歷只寫職稱、時間與技術主題，不放公司內部程式碼的規模數字。
- 不提正在申請研究所；未來方向只寫研究興趣。
- 身分資訊較完整的內容只留在 noindex 的 `/portfolio/`。

## Consequences
- 好處：公開、會被收錄的頁面不會直接連到雇主或全名，也不會讓同事或一般讀者看到升學計畫。
- 好處：事實、時間、用詞仍跟自傳與作品集一致，審查者對照時不會有矛盾。
- 代價：About 頁的說服力比作品集弱，拿不出具體獎項名稱。
- 代價：學校加上競賽類別還是可能搜到官方得獎名單，這種做法只是降低曝光，擋不住有心搜尋的人。
